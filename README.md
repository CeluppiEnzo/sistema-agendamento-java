# Sistema de Agendamento em Java

Sistema de agendamento desenvolvido em Java com o objetivo de praticar programação orientada a objetos e estruturas de dados.

A proposta é simular um sistema utilizado por uma barbearia ou salão de beleza, permitindo o cadastro de clientes, serviços e gerenciamento de agendamentos.

## Funcionalidades

- Cadastro de clientes
- Cadastro de serviços
- Criação de agendamentos
- Listagem de clientes e serviços
- Consulta de agendamentos
- Cancelamento de agendamentos

## Tecnologias utilizadas

- Java
- Programação Orientada a Objetos (POO)
- ArrayList
